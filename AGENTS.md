# Project scope

Copybara Reforged targets World of Warcraft Retail and World of Warcraft: Forever. Forever is a separate game version, not a promise to support Retail forever. Verify each client's current TOC and API contracts before targeting it; do not label offline checks as in-game compatibility.

Preserve the installed Copybara folder, CopybaraDB saved variables, Copybara global, !COPYBARA: format, original attribution, and dependency notices. Preserve import validation and rejection before mutation. Inspect shared runtime paths before removing historical compatibility code.

Use Ponytail Full for coding and review, and Humanizer for public copy. Route substantive implementation and simplification through the existing Bluehost workflow. Keep the urgent Export fix separate from branding and scope changes.

Use the focused Lua mock and real-codec checks documented in README.md for source changes. The current dev.1 package targets Retail only. Verify Forever selectors, interface, APIs, package contents, and actual-client behavior before preparing or advertising a Forever build. Do not install addons or create release tags without authorization.
